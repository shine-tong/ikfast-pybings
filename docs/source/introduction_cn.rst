项目简介
--------

中文文档 | :doc:`English <introduction>`

使用 pybind11 为 IKFast 逆运动学求解器提供的高性能 Python 绑定。本包为 6 自由度机械臂的解析式逆运动学解提供了简洁的 Python 接口，并与 NumPy 无缝集成。
